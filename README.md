## About

**PLASH** is an arcade-style survival game focused on movement, positioning, and physics-driven combat.

You play as **Ael**, a small green monster armed with a bat, trapped in an ever-escalating combat experiment. Waves of enemies spawn endlessly, growing faster and deadlier over time. Your goal is simple: **survive as long as possible, reach the highest wave, and earn the greatest score you can.**

Monitored closely by **Dr. Cabby Greenbeil**, every hit, bounce, and mistake becomes part of the experiment.

---

## Key Features

- **Endless Wave Survival**  
  Enemies spawn in waves with increasing difficulty, speed, and density.  

- **Physics-Based Combat**  
  Smash enemies and balls using momentum, angles, and positioning.  

- **Watermelon Ball System**  
  A powerful ball spawns directly on the player.  
  - Hit it with your bat to deal massive damage  
  - Each hit makes it faster and bouncier  
  - Mastering it is key to surviving high waves

- **Multi-Directional Ball Attacks**  
  Fire smaller balls in all directions to control crowds and escape danger.

- **Dynamic Camera Controls**  
  Zoom in, zoom out, or track the ball mid-fight for better awareness.

- **Night Mode Challenge**  
  Playing after 17:00 unlocks Night Mode, reducing visibility and increasing tension — with an option to disable before battle.

- **Professor-Guided Tutorial with Voice Lines**  
  Learn the mechanics through in-game monologues delivered by Dr. Greenbeil, complete with commentary, impatience, and fourth-wall breaks.

## Controls

### Movement
- **WASD / Arrow Keys** — Move

### Combat
- **Z / Enter** — Attack with bat
- **X / '/'** — Flip bat direction
- **SPACE** — Shoot smaller balls in all directions

### Camera
- **-** — Zoom out  
- **= / +** — Zoom in  
- **0** — Reset camera zoom  
- **B (Hold)** — Focus camera on Watermelon Ball  

### Misc
- **Q** — Cancel Night Mode during countdown

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/nabeellagi/Plash.git
cd Plash
cd game
````

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

### 4. Open the game

Open your browser and navigate to the local address shown in the terminal.
